# Team Task Manager

## 🚀 Features

- User Authentication (Login/Signup)
- Project Management
- Task Assignment & Tracking
- Dashboard with task status
- Role-based access (Admin/Member)

## 🛠 Tech Stack

- Django
- SQLite
- HTML/CSS
